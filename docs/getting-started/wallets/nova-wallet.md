**Nova Wallet** is the official mobile wallet for the Cedra blockchain. Available on Android, Nova Wallet provides a secure and user-friendly way to manage your digital assets.

![Nova Wallet Screenshot](/img/nova-ecosystem/nova-wallet/light.png)

## Download

[**Download directly from Inferenco**](https://inferenco.com/nova-wallet)

## Installation

1. Download Nova Wallet from the Inferenco website
2. Install the application on your Android device
3. Open the app and follow the setup instructions
4. Create a new wallet or import an existing one
5. Your wallet is ready to use!
